COMO LEVAR AO AR

Da edição à publicação

  1. Salve as alterações nos formulários do painel.
  2. Confira as prévias, a ordem e a visibilidade dos perfis.
  3. Clique em Publicar no site no topo da página.
  4. O portal recebe a publicação; visitantes podem levar até 2 minutos para atualizar o conteúdo em cache.
Instruções para quem publica pelo repositório

O arquivo público é assets/data/site.json. Você pode aplicá-lo com node scripts/apply-content.mjs /caminho/naka-site.json, validar e enviar o commit para a branch main. Nunca envie o backup completo como conteúdo público.
